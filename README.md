# Smart-Vendor-Risk-Management-System
A comprehensive full-stack web application designed to streamline the end-to-end vendor lifecycle, from automated onboarding and document collection to risk assessment and performance tracking.

Key Features
1 -> Vendor Onboarding & Management: Centralized dashboard to manage and monitor third-party vendor profiles.
2 -> Automated Questionnaires: Assign and track custom security and compliance questionnaires for thorough due diligence.
3 -> Document Repository: Secure collection and management of essential vendor artifacts, such as ISO certifications and compliance documents.
4 -> Dynamic Risk Scoring: Automated calculation of vendor risk scores based on questionnaire responses and documentation.
5 -> Compliance Monitoring: Real-time tracking of regulatory standards and document expiry alerts. 

Tech Stack 
Laravel 13
package using breeze(auth) + inertia(react) + spatie(laravel-permissions)
